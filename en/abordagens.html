20 outreach examples with context

Twenty original practice situations. This is not a contact list or a message sequence. Read them all, adapt three, and keep them as drafts. Use only truthful facts; respect the channel and any request to stop.

01. Introduction to a studio

When it makes sense: A business channel that accepts proposals.

I’m [name], and I create [service]. I saw [verified fact] about your studio. I have an original study related to [need]. May I send you the example to review?

Exercise status: draft. No message has been sent.

02. Reply to a public request

When it makes sense: The company posted that it is looking for this service.

I saw your request for [deliverable]. I work on [scope] and have a relevant example. How will it be used, and what deadline do you have in mind?

Exercise status: draft. No message has been sent.

03. Authorized referral

When it makes sense: The person named gave permission for the referral.

[Person] gave me permission to mention that your project needs [service]. I’m [name]. Would it make sense to discuss quantity, usage, and timing?

Exercise status: draft. No message has been sent.

04. Someone you already know

When it makes sense: You have actually spoken before.

When we spoke about [topic], you mentioned [need]. I prepared a related original study. Would you like to see it?

Exercise status: draft. No message has been sent.

05. Industry event

When it makes sense: You had a real conversation at the event.

We talked at [event] about [topic]. You asked me to follow up. May I share a sample of my work?

Exercise status: draft. No message has been sent.

06. New collection

When it makes sense: You noticed a launch without assuming interest.

I saw the presentation for [collection]. I make short videos highlighting product details. I have a study clearly labeled as fictional; may I show it so you can assess the format?

Exercise status: draft. No message has been sent.

07. Reply to a requested estimate

When it makes sense: The person asked for an estimate.

To estimate [deliverable], I need to confirm quantity, duration, usage, and timing. Who approves each stage, and which materials are already available?

Exercise status: draft. No message has been sent.

08. Requested portfolio share

When it makes sense: They asked for it or agreed to receive it.

As requested, here is [verified link]. I selected three pieces related to [need]. Each example describes my contribution and the source of its materials.

Exercise status: draft. No message has been sent.

09. Clarify usage

When it makes sense: A pricing conversation is already underway.

Will the video appear only on the brand's profile, or also in a paid ad? That difference affects permissions and proposal terms.

Exercise status: draft. No message has been sent.

10. Clarify the timeline

When it makes sense: You need more information to estimate the schedule.

What date works for the project? To confirm availability, I need to account for receiving materials, approval, and revisions. I can check once those details are clear.

Exercise status: draft. No message has been sent.

11. Scope alternative

When it makes sense: The stated budget does not cover the initial option.

With this budget, I could consider a smaller deliverable: [scope]. It removes [items] and preserves [criteria]. Would you like to compare this option with the original proposal?

Exercise status: draft. No message has been sent.

12. Limited pilot

When it makes sense: There is interest in an evaluation stage.

We can define a paid pilot for [deliverable], with [revision] and [usage]. It does not automatically commit us to a series. May I detail the cost and approval criteria?

Exercise status: draft. No message has been sent.

13. Agreed follow-up

When it makes sense: You previously agreed on a follow-up date.

We agreed to reconnect on [date] after [stage]. Do you have the information we need to move ahead? If the project has changed, I can update the status.

Exercise status: draft. No message has been sent.

14. Relevant one-time follow-up

When it makes sense: Check the channel and context; never follow up after a refusal.

I’m following up once about [topic] to see if it still makes sense. If now is not the right time, I’ll leave it here. You don’t need to explain.

Exercise status: draft. No message has been sent.

15. Request missing information

When it makes sense: A proposal is being prepared without invented urgency.

I still need to confirm [information] to finish the estimate. Send it when you can, and I’ll review the scope. The production timeline still depends on this detail.

Exercise status: draft. No message has been sent.

16. Receipt of comments

When it makes sense: The client sent one round of revisions.

I received the comments. I’ll consolidate them in [list] and check which are in scope. Before doing any additional work, I’ll send the impact for approval.

Exercise status: draft. No message has been sent.

17. Scope change

When it makes sense: A new request exceeds the agreed terms.

Adding [item] adds [work or right]. I’ll estimate the effect on timing and price. The original version remains [scope].

Exercise status: draft. No message has been sent.

18. Decline due to capacity

When it makes sense: You cannot meet the timeline or scope.

Thank you for explaining the project. I can’t take on [condition] with the needed quality by this deadline. I’d rather make that limit clear before we enter an agreement.

Exercise status: draft. No message has been sent.

19. Respectful close

When it makes sense: The person declined or asked you to stop.

Understood. I’ll end this contact and respect your request. Thank you for getting back to me.

Exercise status: draft. No message has been sent.

20. Delivery and optional follow-up

When it makes sense: The actual deliverable has been completed and checked.

The agreed deliverable is at [verified link], with [files]. Check it against the agreed criteria. If a new need comes up, we can consider a separate scope.

Exercise status: draft. No message has been sent.
